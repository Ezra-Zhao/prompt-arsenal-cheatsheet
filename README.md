# 🎯 Prompt Arsenal Cheatsheet · 提示词武器库

One page of battle-tested prompt patterns, one per scenario: copy the prompt, get the result. All prompts original, written clean-room by the author — no copying from prompt collections.

**Full cheatsheets, one per language (written natively, not translated):**

## 中文

12 个高频场景，每行：场景 + 一句可直接复制的提示词 + 一句效果说明。提示词全部原创，不搬运任何提示词库。
覆盖：debug、改简历、数据清洗、画图/PPT、学英语、工作邮件、读书总结、翻译、面试准备、学新技术、周报、头脑风暴。

## Español

12 escenarios frecuentes: escenario + un prompt listo para copiar + por qué funciona. Todos los prompts son originales.
Cubre: depurar código, CV, limpiar datos, presentaciones, inglés, emails, resumir libros, traducir, entrevistas, aprender tecnología, reportes e ideas.

## Português

12 cenários frequentes: cenário + um prompt pronto para copiar + por que funciona. Todos os prompts são originais.
Cobre: depurar código, currículo, limpar dados, apresentações, inglês, e-mails, resumir livros, traduzir, entrevistas, aprender tecnologia, relatórios e ideias.
